## 📐 4. Formatos Recomendados para Campañas

1. **Post Cuadrado (1:1 - 1080 x 1080 px):**
   - Ideal para feed de Instagram y Facebook. 1 imagen por plan o carrusel de 4 láminas (Lámina 1: Portada comparativa, Láminas 2-4: Detalles de cada plan, Lámina 5: Métodos de pago Yape y WhatsApp).
2. **Historias y Reels / TikTok (9:16 - 1080 x 1920 px):**
   - Formato vertical con textos grandes, precios destacados en círculos o pastillas amarillas/verdes y flecha señalando al enlace de WhatsApp.
3. **Banner Web Horizontal (1200 x 630 px):**
   - Para compartir en WhatsApp (Open Graph preview) o pauta de display.
