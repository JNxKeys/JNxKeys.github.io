# 📱 Guía Maestra de Respuestas Automáticas para WhatsApp (JNxKeys)

Esta guía contiene la configuración oficial de respuestas automáticas para **WhatsAuto** en la tablet de JNxKeys, estructurada para copiar y pegar cada regla fácilmente.

> **Configuración global en WhatsAuto (Opción Gratuita · Uno a Uno):**
> 1. Abre WhatsAuto en tu tablet.
> 2. Entra a **"Respuesta por palabra clave"**.
> 3. Toca en el botón **`+`** (crear regla).
> 4. En **Opciones de coincidencia**, selecciona siempre **"Contiene"** (para que responda aunque el cliente escriba un saludo antes o después).
> 5. Pega las palabras clave y el texto de respuesta correspondiente.
> 6. Guarda con el check (✓) arriba a la derecha.
